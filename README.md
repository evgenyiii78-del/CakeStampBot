# CakeStampBot v0.8.5

Stable Topper Geometry:

- убран проблемный `Topper_ONEPIECE`, который давал рваную/non-manifold модель;
- топпер теперь состоит из двух чистых объектов в одном 3MF:
  - `Topper_Base` — скруглённая подложка-перемычка + ножка/ножки;
  - `Topper_Text` — текст сверху, утопленный в базу на 0.2 мм;
- убрана огромная Т-образная подложка;
- убраны сложные перемычки между каждой буквой;
- геометрия стала проще и стабильнее для Bambu Studio / OrcaSlicer;
- модель должна меньше чиниться слайсером.

Это более правильный подход для печати: отдельные корректные объекты в 3MF, собранные на месте.


# CakeStampBot v0.8.5

Исправление топпера:

- убрано превью с большой прямоугольной табличкой;
- топпер теперь показывается как узкая подложка под текстом + ножка/ножки;
- в 3MF подложка стала не большой плитой, а letter-shaped backing + тонкая соединительная перемычка;
- авто-ножки изменены:
  - 90 мм и 120 мм → одна ножка;
  - 145+ мм → две ножки;
- версия в логах и `/start` обновлена до v0.8.5.


# CakeStampBot v0.8.5

## Hotfix v0.8.5

- исправлена ошибка `Ошибка: 'text'` при создании топпера;
- добавлена защита: задача топпера не отправляется в очередь, если текст не сохранён;
- поддержаны старые callback-кнопки ножек: `legs:*`, `topper_leg:*`, `topper_legs:*`;
- топперный сценарий теперь стабильнее проходит: текст → шрифт → ширина → высота текста → подложка → ножки → создать.


Чистая версия проекта.

## Что изменилось

- Вырубка полностью удалена.
- Остались только два режима: 🍰 **Штамп** и 🎂 **Топпер**.
- Логика разделена на отдельные движки:
  - `engine/stamp_engine.py`
  - `engine/topper_engine.py`
  - `engine/common.py`
- Топпер теперь строится правильно:
  - текст отдельным объектом;
  - подложка под буквами, чтобы надпись была единой;
  - одна или две ножки;
  - авто-выбор двух ножек для широких топперов;
  - выбор высоты текста;
  - выбор толщины подложки под буквами.

## Запуск Windows CMD

```cmd
py -3.12 -m venv .venv
.venv\Scripts\python.exe -m pip install --upgrade pip setuptools wheel
.venv\Scripts\python.exe -m pip install -r requirements.txt
copy .env.example .env
notepad .env
.venv\Scripts\python.exe scripts\smoke_test.py
.venv\Scripts\python.exe bot.py
```

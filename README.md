# CakeStampBot v0.3

Telegram-бот для теста идеи **Cake Stamp Studio**.

## Что нового в v0.3

- выбор режима изделия:
  - **Штамп**
  - **Топпер**
  - **Вырубка**
- выбор сердечка кнопкой **Да / Нет**;
- выбор толщины линии:
  - 0.35 мм
  - 0.45 мм
  - 0.60 мм
  - 0.80 мм
- выбор шрифта для текста:
  - Classic
  - Comic Sans MS
  - GOST type AU
- очередь задач;
- более аккуратный интерфейс Telegram-бота;
- `lxml` уже добавлен в `requirements.txt`;
- smoke-test для проверки без Telegram.

## Режимы

### Штамп

Создаёт 3MF-проект с отдельными объектами:

- `Base`
- `Relief`
- `Heart`, если включено

Параметры по умолчанию:

- подложка Ø105 мм;
- толщина подложки 0.7 мм;
- высота рельефа 6.5 мм.

### Топпер

Создаёт отдельную плоскую модель без круглой подложки.

Пока это MVP-режим: форма строится из того же рельефа, но как самостоятельный объект.

### Вырубка

Создаёт контурную стенку по силуэту изображения/текста.

Параметры MVP:

- высота стенки 12 мм;
- минимальная толщина стенки не меньше 0.8 мм.

## Установка на Windows через CMD

Открой обычную командную строку:

```cmd
Win + R
cmd
Enter
```

Перейди в папку проекта:

```cmd
cd /d C:\Users\user\Downloads\CakeStampBot_v0_3\CakeStampBot_v0_3
```

Создай виртуальное окружение на Python 3.12:

```cmd
py -3.12 -m venv .venv
```

Установи зависимости:

```cmd
.venv\Scripts\python.exe -m pip install --upgrade pip setuptools wheel
.venv\Scripts\python.exe -m pip install -r requirements.txt
```

## Проверка без Telegram

```cmd
.venv\Scripts\python.exe scripts\smoke_test.py
```

Должно быть:

```text
Smoke test PASS
```

## Настройка Telegram

Создай `.env`:

```cmd
copy .env.example .env
notepad .env
```

Впиши токен:

```env
BOT_TOKEN=твой_токен_бота
```

Запуск:

```cmd
.venv\Scripts\python.exe bot.py
```

## Шрифты

Classic и Comic Sans MS обычно находятся автоматически на Windows.

Для GOST type AU шрифт нужно установить в Windows или указать путь в `.env`:

```env
CAKESTAMP_FONT_GOST=C:\Windows\Fonts\GOST type AU.ttf
```

Файлы шрифтов в архив не включены.

## Важно

Это тестовый MVP. Он нужен, чтобы проверить UX, 3MF-проект и работу очереди.

Для хорошего результата в режиме картинки лучше использовать:

- чёрный рисунок на белом фоне;
- простой логотип;
- без теней и градиентов;
- без мелкого шума.
